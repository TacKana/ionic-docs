将 Appflow git 远程仓库添加/更新到您的本地 Ionic 应用

```shell
$ ionic git remote
```

此命令由 `ionic link` 在将 Appflow 用作 git 托管服务时使用。

`ionic git remote` 将检查本地仓库以确认 git 远程仓库是否已正确设置。此命令操作的是 **ionic** 远程仓库。有关高级配置，请参见 [Dashboard](https://dashboard.ionicframework.com) 应用设置中的 **设置** => **Git**。
