自动设置您的 Ionic SSH 密钥

```shell
$ ionic ssh setup
```

此命令通过一系列提示提供 Ionic SSH 密钥的设置向导。如需更多控制，请参见 `ionic ssh --help` 命令下可用于管理 SSH 密钥的命令。如需完全手动操作，请参见 [Dashboard](https://dashboard.ionicframework.com/settings/ssh-keys) 中的 **个人设置** => **SSH 密钥**。

如果您在设置 SSH 密钥时遇到问题，请联系我们的 [支持](https://ion.link/support-request)。
