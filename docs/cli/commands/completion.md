启用 Ionic CLI 命令的 Tab 补全功能。

```shell
$ ionic completion
```

此命令为实验性功能，仅适用于 Z shell（zsh）和非 Windows 平台。

要为 Ionic CLI 启用补全功能，您可以将此命令输出的补全代码添加到您的 **~/.zshrc**（或 shell 加载的任何其他文件）中。参见示例。

## 示例

```shell
$ ionic completion 
$ ionic completion >> ~/.zshrc
```
