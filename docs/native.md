使用由 Ionic 团队构建的原生运行环境 Capacitor，为您的应用添加原生功能。安装核心包即可轻松将其添加到您的项目中。Capacitor 拥有广泛的能力，开发者可以借此访问设备文件系统、相机和原生定位服务等功能。所有这些都由一个统一的 TypeScript API 驱动，该 API 自动处理平台差异。

虽然 Capacitor 的核心功能是免费且开源的，但一些企业可能需要更多功能或自定义第三方集成。如果您需要此类额外功能，请查看 [Ionic Enterprise SDK](https://ionic.io/enterprise-sdk)。
