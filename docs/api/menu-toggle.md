Menu Toggle 组件可用于切换菜单的打开或关闭。

菜单切换仅当选中的菜单启用时才可见。如果菜单被禁用或作为拆分面板显示，菜单切换将被隐藏。要始终显示菜单切换，可以将 `autoHide` 属性设置为 `false`。

更多信息请参阅 [menu](./menu#菜单切换) 文档。
