`ion-infinite-scroll-content` 组件是 `ion-infinite-scroll` 使用的默认子组件。它显示一个根据平台看起来最佳的无限滚动旋转器，并根据无限滚动的状态改变外观。可以通过设置 `loadingSpinner` 和 `loadingText` 属性来更改默认旋转器和添加文本。

有关更多信息以及用法，请参阅[无限滚动文档](./infinite-scroll.md#加载文本和旋转器)。
