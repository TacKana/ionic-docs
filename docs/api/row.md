行是[网格](./grid)系统的水平组件，包含不同数量的[列](./col)。它们确保列被正确放置。

有关更多信息，请参阅[网格](./grid)文档。


## 行对齐

默认情况下，列会拉伸以填充行的整个高度，并在必要时换行。行是[弹性容器](https://developer.mozilla.org/en-US/docs/Glossary/Flex_Container)，因此有几种[CSS类](/layout/css-utilities#flex-容器属性)可以应用于行来自定义此行为。
