fab 列表组件是多个 [fab 按钮](./fab-button)的容器。它包含与主 fab 按钮相关的操作，并在点击时弹出。要指定按钮应出现在哪一侧，请将 `side` 属性设置为 `"start"`、`"end"`、`"top"` 或 `"bottom"`。

使用示例请参阅 [fab 文档](./fab)。
