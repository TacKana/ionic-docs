# 版本控制

<!-- TOC goes here -->

Ionic Framework 遵循 <a href="https://semver.org/" target="_blank">语义化版本控制（SemVer）</a>规范：<code>major.minor.patch.</code> 不兼容的 API 变更会增加 <code>major</code>（主）版本号，向后兼容的功能添加会增加 <code>minor</code>（次）版本号，向后兼容的 bug 修复会增加 <code>patch</code>（补丁）版本号。

## 发布计划

### 主版本发布

当 API 中引入破坏性变更时，将发布主版本。主版本大约每 **6 个月**发布一次，可能包含破坏性变更。在主版本最终发布之前，会发布多个候选版本以收集反馈。候选版本将附带变更内容和原因的概述。

### 次版本发布

当添加新功能或引入非破坏性的 API 变更时，将发布次版本。我们将对任何更改进行严格测试，以确保对版本有信心，但新代码总是可能带来新问题。如果有任何功能或 API 变更，我们计划**每 4 周**发布一个次版本。

### 补丁版本发布

当包含 bug 修复但 API 未变更且未引入破坏性变更时，将发布补丁版本。我们计划**每周**发布一个新的补丁版本，但有时可能需要提前或推迟发布。为确保补丁版本能够修复现有代码而不引入新功能带来的新问题，补丁版本总是在次版本之前发布。

## 变更日志

要查看 Ionic 所有显著更改的列表，请参阅 <a href="https://github.com/ionic-team/ionic/blob/master/CHANGELOG.md" target="_blank">变更日志</a>。它包含每个版本下所有 bug 修复和新功能的有序列表。
