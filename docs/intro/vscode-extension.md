[WebNative Visual Studio Code 扩展](https://marketplace.visualstudio.com/items?itemName=WebNative.webnative)是一个社区维护的插件，可帮助您执行常见的 Ionic Framework 开发任务，无需记忆 CLI 命令。

如果您在此计算机上安装了 VS Code，请点击下方的"安装"按钮。您也可以通过搜索"WebNative"找到该扩展。

<a href="vscode:extension/webnative.webnative" target="_self">
  <button className="install-button">安装</button>
</a>
<a href="https://webnative.dev/introduction/getting-started/" target="_self">
  <button className="docs-button">文档</button>
</a>

## 附加文档

WebNative 扩展的完整文档可在 [webnative.dev](https://webnative.dev/introduction/getting-started/) 找到，涵盖以下主题：

- 构建、调试和运行您的 Ionic Framework 应用。
- 包分析、依赖升级。
- 从 Cordova 迁移。
- 更改原生设置。
- 启动屏与图标。
- 使用 WebNative 应用在没有 Mac 的情况下进行开发。
