# 从 Ionic 6 升级到 7

:::note
本指南假定您已将应用更新到 Ionic 6 的最新版本。在开始本指南之前，请确保您已遵循[升级到 Ionic 6 指南](./6-0)。
:::

:::info 破坏性变更
有关从 Ionic 6 到 Ionic 7 的**完整破坏性变更列表**，请参阅 Ionic Framework 仓库中的[破坏性变更文档](https://github.com/ionic-team/ionic-framework/blob/main/BREAKING.md#version-7x)。
:::

## 开始之前

### Angular

1. Ionic 7 支持 Angular 14+。请按照 [Angular 更新指南](https://update.angular.io/) 更新到最新版本的 Angular。
2. 如果您的项目使用了 rxjs，Ionic 7 要求最低 rxjs 版本为 7.5.0：

```shell
npm install rxjs@7.5.0
```

3. 更新到最新版本的 Ionic 7：

```shell
npm install @ionic/angular@7
```

如果您正在使用 Ionic Angular Server 和 Ionic Angular Toolkit，请确保也更新它们：

```shell
npm install @ionic/angular@7 @ionic/angular-server@7 @ionic/angular-toolkit@9
```

> 注意：`@ionic/angular-toolkit@9` 要求最低 Angular 15 版本。如果您仍在使用 Angular 14，则可以跳过更新 `@ionic/angular-toolkit@9`。

### React

1. Ionic 7 支持 React 17+。更新到最新版本的 React：

```shell
npm install react@latest react-dom@latest
```

2. 更新到最新版本的 Ionic 7：

```shell
npm install @ionic/react@7 @ionic/react-router@7
```

### Vue

1. Ionic 7 支持 Vue 3.0.6+。更新到最新版本的 Vue：

```shell
npm install vue@latest vue-router@latest
```

3. 更新到最新版本的 Ionic 7：

```shell
npm install @ionic/vue@7 @ionic/vue-router@7
```

### Core

1. 更新到最新版本的 Ionic 7：

```shell
npm install @ionic/core@7
```

## 更新您的代码

### 浏览器支持

Ionic 支持的浏览器列表已更改。请查看[浏览器支持指南](../reference/browser-support)以确保您的应用部署到支持的浏览器。

如果您有 `browserslist` 或 `.browserslistrc` 文件，请将其更新为以下内容：

```
Chrome >=79
ChromeAndroid >=79
Firefox >=70
Edge >=79
Safari >=14
iOS >=14
```

### 类型

1. `ActionSheetAttributes`、`AlertAttributes`、`AlertTextareaAttributes`、`AlertInputAttributes`、`LoadingAttributes`、`ModalAttributes`、`PickerAttributes`、`PopoverAttributes` 和 `ToastAttributes` 已被移除。开发者应改用 `{ [key: string]: any }`。

### Checkbox

1. 将所有 `--background` 和 `--background-checked` CSS 变量的使用分别重命名为 `--checkbox-background` 和 `--checkbox-background-checked`。

### Datetime

1. 移除所有将 `value` 属性设置为空字符串（`''`）的代码。
2. 移除所有访问 `value` 属性上时区信息的代码。Datetime 不管理时区，因此提供的任何时区信息都将被忽略。

### Input

1. 将所有访问 `ionInput` 事件 `detail` 载荷的代码从 `event.detail` 更新为 `event.detail.value`，因为 detail 载荷现在是一个包含 value 和 event 的对象。

### Modal

1. 移除所有 `swipeToClose` 属性的使用。卡片模态框默认是可滑动的，因此如果您希望卡片模态框保持可滑动，可以移除 `swipeToClose`。如果您想阻止模态框关闭，请使用 [canDismiss](https://ionicframework.com/docs/api/modal#preventing-a-modal-from-dismissing) 属性。
2. 移除所有将 `canDismiss` 属性设置为 `undefined` 的代码。`canDismiss` 属性现在默认值为 `true`，因此不再需要此代码。

### Picker

1. 移除所有访问 `ion-picker-column` 上 `refresh` 的代码。开发者应改用 `ion-picker` 上的 `columns` 属性来刷新视图。

### Searchbar

1. 将所有访问 `ionInput` 事件 `detail` 载荷的代码从 `event.detail` 更新为 `event.detail.value`，因为 detail 载荷现在是一个包含 value 和 event 的对象。

### Segment

1. 移除所有将 `value` 属性设置为 `null` 的代码。开发者应改用 `''` 或 `undefined`。

### Slides

1. 移除 `ion-slides`、`ion-slide` 以及所有相关类型。这些组件已被移除，建议直接使用 Swiper.js。以下指南包含有关此迁移的更多信息：

[Angular 迁移指南](https://ionicframework.com/docs/angular/slides)<br />
[React 迁移指南](https://ionicframework.com/docs/react/slides)<br />
[Vue 迁移指南](https://ionicframework.com/docs/vue/slides)

### Textarea

1. 将所有访问 `ionInput` 事件 `detail` 载荷的代码从 `event.detail` 更新为 `event.detail.value`，因为 detail 载荷现在是一个包含 value 和 event 的对象。

### Toggle

1. 将所有 `--background` 和 `--background-checked` CSS 变量的使用分别重命名为 `--track-background` 和 `--track-background-checked`。

### Virtual Scroll

1. 移除 `ion-virtual-scroll` 以及所有相关类型。此组件已被移除，建议使用 JavaScript 框架提供的虚拟滚动解决方案。以下指南包含有关此迁移的更多信息：

[Angular 迁移指南](https://ionicframework.com/docs/angular/virtual-scroll)<br />
[React 迁移指南](https://ionicframework.com/docs/react/virtual-scroll)<br />
[Vue 迁移指南](https://ionicframework.com/docs/vue/virtual-scroll)

如果您需要升级帮助，请在 [Ionic 论坛](https://forum.ionicframework.com/)上发帖。
