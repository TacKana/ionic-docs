# 版本控制

<!-- TOC goes here -->

Ionic Framework 遵循 <a href="https://semver.org/" target="_blank">语义化版本控制 (SemVer)</a> 规范：<code>major.minor.patch</code>。不兼容的 API 更改会增加 <code>major</code> 版本，添加向后兼容的功能会增加 <code>minor</code> 版本，向后兼容的错误修复会增加 <code>patch</code> 版本。

## 发布计划

### 主要版本

当 API 引入重大更改时，将发布主要版本。主要版本大约每 **6 个月** 发布一次，可能包含重大更改。在最终版本发布之前，将发布多个候选版本以收集反馈。候选版本将包含有关更改内容及其原因的概述。

### 次要版本

当添加新功能或引入非破坏性的 API 更改时，将发布次要版本。我们将对任何更改进行充分测试，以便我们对版本发布有信心，但新代码总是可能带来新问题。如果进行了任何功能或 API 更改，我们计划**每 4 周**发布一个次要版本。

### 补丁版本

当包含错误修复但 API 未更改且未引入重大更改时，将发布补丁版本。我们计划**每周**发布一个新的补丁版本，但有时可能需要比计划更早或更晚发布。为确保补丁版本可以修复现有代码而不引入新功能带来的新问题，补丁版本总是在次要版本之前发布。

## 更新日志

要查看 Ionic 所有重要更改的列表，请参阅 <a href="https://github.com/ionic-team/ionic/blob/master/CHANGELOG.md" target="_blank">更新日志</a>。其中包含每个版本下所有错误修复和新功能的有序列表。
