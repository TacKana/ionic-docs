### [Elite Ionic](https://www.joshmorony.com/elite/)

<!-- cspell:disable-next-line -->

作者：Josh Morony

Elite Ionic 是一门面向 Ionic 开发者的在线课程，旨在帮助开发者超越基础，构建复杂、经过良好测试、高性能、美观且易用的移动应用程序。建议在开始本课程之前，您已具备 reasonably 扎实的 Ionic 基础知识。

通过 Ionic 社区领袖之一提供的逐步视频课程和快速技巧学习 Ionic。涵盖初级、中级和高级主题。获取与像您一样的开发者社区交流的机会。

### [Ionic Framework: Tips, Tricks & Techniques](https://www.packtpub.com/mobile/ionic-framework-tips-tricks-and-techniques-video)

<!-- cspell:disable-next-line -->

作者：Charles Muzonzini

在本课程中，您将掌握 Ionic 4 和 Ionic 5 的技巧与最佳实践，并可立即应用以构建高质量的应用程序。本课程涵盖从提升应用性能、构建自定义原生插件到保护应用安全的广泛主题。这是一个实用的动手课程，将把您的应用构建技能提升到新的水平。

### [Building Desktop Apps with Ionic and Electron](https://pluralsight.pxf.io/VeMXO)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

桌面开发历来需要与 Web 开发截然不同的技能。这两个领域难以很好地融合。在本课程《使用 Ionic 和 Electron 构建桌面应用》中，您将学会运用来之不易的 Web 开发技能来构建出色的桌面应用程序。首先，您将学习如何使用 Ionic 和 Angular 构建功能完善且美观的 UI。接下来，您将发现如何将该 UI 封装到 Electron 应用程序壳中。最后，您将探索如何打包应用并使其准备好分发。完成本课程后，您将掌握使用 Ionic 和 Electron 开发、部署和分发适用于 Windows 和 macOS 用户的精美应用所需的技能和知识。

### [Building Progressive Web Apps with Ionic](https://pluralsight.pxf.io/Ly2EY)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

当 Google 提出渐进式 Web 应用程序（PWA）的概念时，一切都改变了。PWA 是一种纯 Web 应用程序，您可以将其安装到设备上，并通过智能缓存在网络功能受限的情况下运行。构建一个可在任何地方运行的渐进式 Web 应用。在本课程《使用 Ionic 构建渐进式 Web 应用》中，您将学习基础知识，并掌握创建可在浏览器、桌面或移动客户端上运行的 Web 应用的能力。首先，您将了解什么是渐进式 Web 应用（PWA）。接下来，您将发现如何使用 Ionic Framework、Angular 和 Firebase 来创建、部署和优化一个基础 Web 应用，使其成为完整的 PWA。最后，您将探索如何配置应用，使其可在 Android 和 iPhone 上安装和运行。完成本课程后，您将掌握使用 Ionic 和 PWA 创建和部署渐进式 Web 应用的技能和知识。

### [Ionic CLI](https://pluralsight.pxf.io/ionic-cli)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

自诞生以来，Ionic Framework 就包含了一个基本的命令行界面。虽然只有几年的历史，但它已经发展成为一个强大的工具，应该是每个开发者工具箱中的一部分。本课程《Ionic CLI》将从头开始探索 Ionic CLI。首先，您将了解如何创建项目和组件。接下来，您将学习如何构建和提供应用服务。最后，您将发现如何与他人共享项目，甚至与其他构建工具集成。无论您是刚刚开始探索 Ionic，还是从预测试版时代就开始使用它，这里都有适合您的内容。课程结束时，您将能够自信地将 Ionic CLI 作为日常 Ionic 开发的一部分来使用。
