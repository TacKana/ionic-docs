# 行为准则

作为 Ionic 项目的贡献者和维护者，我们承诺尊重每一个通过发布 issue、更新文档、提交 Pull Request、在评论中提供反馈以及任何其他活动来贡献的人。

通过 Ionic 的任何渠道（GitHub、Slack、论坛、IRC、邮件列表、Twitter 等）进行的交流必须具有建设性，不得进行人身攻击、恶意挑衅、公开或私下的骚扰、侮辱或其他不专业的行为。

我们承诺向参与此项目的每个人提供礼貌和尊重，无论其性别、性别认同、性取向、残疾、年龄、种族、民族、宗教或经验水平如何。我们希望任何为 Ionic 项目做出贡献的人都能同样做到。

如果任何社区成员违反了此行为准则，Ionic 项目的维护者可以根据其认为适当的方式采取行动，包括移除 issue、评论和 PR，或封锁账号。

如果您遭受或目击了不可接受的行为，或有任何其他疑虑，请发送电子邮件至 <a href="mailto:devrel@ionic.io">devrel@ionic.io</a>。

请点击<a href="https://ionic.io/code-of-conduct" target="_blank" rel="noopener">此处</a>查看 Ionic 的完整行为准则。
