更新 Capacitor 原生平台，安装 Capacitor/Cordova 插件

```shell
$ ionic capacitor update [platform]
```

`ionic capacitor update` 将执行以下操作：
- 更新 Capacitor 原生平台和依赖
- 安装任何发现的 Capacitor 或 Cordova 插件

### platform
要更新的平台（例如 `android`、`ios`）
