导航链接用于导航到指定组件。可以通过 `forward`（前进）、`back`（返回）或作为 `root`（根）组件来导航到该组件。

它是在导航控制器上调用 `push()`、`pop()` 和 `setRoot()` 方法的元素形式。

更多信息请参阅 [nav](./nav#使用-navlink) 文档。
