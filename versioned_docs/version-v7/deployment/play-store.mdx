## 生成应用的发布构建

<Tabs groupId="runtime">
<TabItem value="capacitor" label="Capacitor" default>
要为 Android 生成发布构建，请构建您的 Web 应用，然后运行以下 CLI 命令：

```shell
npx cap copy && npx cap sync
```

这将复制所有 Web 资源并同步任何插件更改。

接下来，打开 Android Studio：

```shell
npx cap open android
```

</TabItem>
<TabItem value="cordova" label="Cordova">
要为 Android 生成发布构建，请运行以下 CLI 命令：

```shell
ionic cordova build android --prod --release
```

这将根据应用的 `platforms/android/app/build/outputs/apk` 目录中 `config.xml` 的设置生成发布构建。
Ionic 应用在此文件中预设了默认值，但可以更改以自定义构建。

</TabItem>
</Tabs>

## 签署 APK

<Tabs groupId="runtime">
<TabItem value="capacitor" label="Capacitor" default>
要在本地使用 Android Studio 创建 AAB 二进制文件：

- 打开 Build 菜单
- 选择 **Generate Signed Bundle / APK**
- 按照提示使用您的 keystore 文件签署 AAB

有关完整详细信息，[查看 Android 文档](https://developer.android.com/studio/publish/app-signing)。

### Google Play 签名

如果您尚未切换到 Android App Bundle 格式，您需要在 Google Play Console 中启用 Play App Signing 才能发布它们。

#### 新应用

首先，在 Google Play Console 中创建一个新应用。要启用应用签名，您需要导航到新的版本发布页面，在 Production、Open testing、closed testing 或 internal testing 页面之一中。
选择 **Create new release** 按钮，如下所示（选择哪种发布类型都无所谓，因为您现在不必真正完成新版本的发布）：

![Google Play Console 的 Production 标签页，箭头指向'Create new release'按钮。](https://blog.ionicframework.com/wp-content/uploads/2021/12/newapps-release-1024x561.png "Google Play Console 新建版本")

在 App integrity 部分下，点击 **Change app signing key** 按钮：

![Google Play Console 的 App integrity 部分，'Change app signing key'按钮高亮显示。](https://blog.ionicframework.com/wp-content/uploads/2021/12/newapps-signingkey.png "Google Play Console 更改应用签名密钥选项")

接下来，选择 **Export and upload a key from Java Keystore** 选项。这是您可以保留密钥并让 Google Play 使用它进行签名的唯一方式。如果您使用 Appflow 在云端构建 Android 应用，这也是必需的选项，以便将 keystore 文件上传到 Appflow。

![Google Play Console 显示'Export and upload a key from Java Keystore'选项。](https://blog.ionicframework.com/wp-content/uploads/2021/12/newapps-export-1024x564.png "Google Play Console 导出并上传密钥选项")

按照屏幕上的说明生成 Keystore，您也可以使用相同的 Keystore 文件在 Appflow 仪表板中签署您的应用。如果需要生成 Keystore 文件的帮助，可以参考我们的[文档](https://ionic.io/docs/appflow/package/credentials#android-certificates)。
上传生成的 zip 文件后，您就准备好了！构建一个使用 keystore 文件签署的 AAB 二进制文件，然后上传到 Google Play。

#### 现有应用

截至目前，现有应用不需要使用 AAB 格式，但您仍然可以使用 Play App Signing 来注册它们。

要选择应用签名，您需要上传用于签署以前版本应用的应用签名密钥。导航到 Setup -> App integrity，然后选择下方截图中看到的两种方法之一。上传密钥后，您就可以注册 Play App Signing。

![Google Play Console 中 Play App Signing 的注册选项。](https://blog.ionicframework.com/wp-content/uploads/2021/12/existingapps-optin.png "Google Play Console 注册 Play App Signing")

:::tip
更小的应用体积、更好的性能和更强的安全性，使 AAB 二进制格式对应用开发者和用户来说都是一大优势。如果您有使用 APK 格式的现有 Android 应用，考虑迁移到 AAB 以利用其提供的所有优秀功能。
:::

</TabItem>
<TabItem value="cordova" label="Cordova">
首先，未签名的 APK 必须进行签名。如果已经生成了签名密钥，请跳过这些步骤，使用已有的密钥。
使用 Android SDK 附带的 keytool 命令生成私钥：

```shell
keytool -genkey -v -keystore my-release-key.keystore -alias alias_name -keyalg RSA -keysize 2048 -validity 10000
```

运行该命令并回答提示后，会在当前目录中创建一个名为 `my-release-key.keystore` 的文件。

:::caution
保存此文件并将其放在安全的地方。如果丢失，Google Play Store 将不接受此应用的更新！
:::

要签署未签名的 APK，请运行同样包含在 Android SDK 中的 jarsigner 工具：

```shell
jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 -keystore my-release-key.keystore HelloWorld-release-unsigned.apk alias_name
```

最后，必须运行 zip align 工具来优化 APK。
`zipalign` 工具可以在 `/path/to/Android/sdk/build-tools/VERSION/zipalign` 找到。
例如，在安装了 Android Studio 的 macOS 上，`zipalign` 位于 `~/Library/Android/sdk/build-tools/VERSION/zipalign`：

```shell
zipalign -v 4 HelloWorld-release-unsigned.apk HelloWorld.apk
```

这将生成一个名为 HelloWorld.apk 的最终发布二进制文件，可以提交到 Google Play Store。

</TabItem>

## 将应用提交到 Google Play Store

现在已生成发布 AAB/APK，可以编写 Play Store 列表并上传 AAB/APK。

首先，访问 [Google Play Store Developer Console](https://play.google.com/apps/publish) 并创建一个新的开发者账号。

:::note
创建 Google Play 开发者账号需要 25 美元。
:::

创建开发者账号后，点击 `Create an Application`

![Google Play Store Developer Console，'CREATE APPLICATION'按钮高亮显示。](/img/publishing/newAppGPlay.png "Google Play Store 创建应用按钮")

请确保填写应用的描述，并提供截图和其他信息。
准备就绪后，上传生成的已签名发布 AAB/APK 并发布应用。

## 更新应用

随着应用的发展，需要通过新功能和修复进行更新。应用可以通过向 Google Play Store 提交新版本，或使用实时更新服务（如 Appflow 的 Live Update 功能）来更新。使用 Live Updates，可以直接从 Appflow 仪表板向用户推送更改，而无需提交更改到 Play Store。在此处了解更多关于 Live Updates 的信息 <a href="https://ionic.io/docs/appflow/deploy/intro" target="_blank">here</a>。
