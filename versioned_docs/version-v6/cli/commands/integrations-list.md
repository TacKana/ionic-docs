列出应用中可用和已激活的集成

```shell
$ ionic integrations list
```

此命令将打印 Ionic 项目中集成的状态。集成可以是 **enabled**（已添加并启用）、**disabled**（已添加但已禁用）和 **not added**（从未添加到项目）。

- 要启用或添加集成，请参见 `ionic integrations enable --help`
- 要禁用集成，请参见 `ionic integrations disable --help`
