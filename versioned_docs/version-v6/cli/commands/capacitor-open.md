为指定的原生平台项目打开 IDE

```shell
$ ionic capacitor open [platform]
```

`ionic capacitor open` 将执行以下操作：
- 打开您的原生项目的 IDE（iOS 为 Xcode，Android 为 Android Studio）

### platform
要打开的平台（例如 `android`、`ios`）
