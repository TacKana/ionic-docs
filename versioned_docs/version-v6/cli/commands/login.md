登录 Ionic

```shell
$ ionic login [email] [password]
```

通过 Ionic 进行身份验证并获取用户令牌，该令牌存储在 CLI 配置中。运行 `ionic login` 将打开一个浏览器，您可以在其中提交凭据。

如果设置了 `IONIC_TOKEN` 环境变量，CLI 将自动验证您的身份。使用 Dashboard 生成个人访问令牌。

如果您需要创建 Ionic 账户，请使用 `ionic signup` 或访问 Ionic [网站](https://ionicframework.com/signup)。

如果您在登录时遇到问题，请联系我们的 [支持](https://ion.link/support-request)。

### email
您的电子邮件地址（已弃用）


### password
您的密码（已弃用）



## 示例

```shell
$ ionic login 
```
