# 课程

### [Elite Ionic](https://www.joshmorony.com/elite/)

<!-- cspell:disable-next-line -->

作者：Josh Morony

Elite Ionic 是一门面向 Ionic 开发者的在线课程，他们希望超越基础知识，构建复杂、经过良好测试、高性能、美观且可用的移动应用。建议在开始本课程之前，您已经对 Ionic 的基础知识有相当扎实的理解。

### [Ionic Academy](https://ionicacademy.com/)

<!-- cspell:disable-next-line -->

作者：Simon Grimm

通过来自 Ionic 社区领袖之一的分步视频课程和快速技巧学习 Ionic。涵盖初学者、中级和高级主题。加入一个像您一样的开发者社区。

### [Ionic Framework：技巧、窍门和技术](https://www.packtpub.com/mobile/ionic-framework-tips-tricks-and-techniques-video)

<!-- cspell:disable-next-line -->

作者：Charles Muzonzini

在本课程中，您将掌握 Ionic 4 和 Ionic 5 的技巧和最佳实践，可以立即实施以构建高质量应用。本课程涵盖从提高应用性能、构建自定义原生插件到保护应用安全等广泛主题。这是一门实践性强的动手课程，将把您的应用构建技能提升到新的水平。

### [使用 Ionic 和 Electron 构建桌面应用](https://pluralsight.pxf.io/VeMXO)

<!-- cspell:disable-next-line -->

作者：Pluralsight 的 Michael Callaghan

桌面开发历来需要与 Web 开发截然不同的技能。这两门学科不太契合。在本课程"使用 Ionic 和 Electron 构建桌面应用"中，您将获得将您辛苦获得的 Web 开发技能应用于构建出色的桌面应用的能力。首先，您将学习如何使用 Ionic 和 Angular 构建功能齐全且吸引人的 UI。接下来，您将发现如何将该 UI 封装到 Electron 应用壳中。最后，您将探索如何打包应用并使其准备好分发。完成本课程后，您将拥有将美观的应用部署和分发给 Windows 和 macOS 用户所需的 Ionic 和 Electron 开发技能和知识。

### [使用 Ionic 构建渐进式 Web 应用](https://pluralsight.pxf.io/Ly2EY)

<!-- cspell:disable-next-line -->

作者：Pluralsight 的 Michael Callaghan

当 Google 创建了渐进式 Web 应用（PWA）的概念后，一切发生了变化。PWA 是一种纯 Web 应用，您可以将其安装到设备上，通过智能缓存的使用，它可以在有限的网络功能下运行。构建一个随处可运行的渐进式 Web 应用。在本课程"使用 Ionic 构建渐进式 Web 应用"中，您将学习基础知识，并获得创建可在任何地方运行的 Web 应用的能力：浏览器、桌面或移动客户端。首先，您将了解什么是渐进式 Web 应用（PWA）。接下来，您将发现如何使用 Ionic Framework、Angular 和 Firebase 来创建、部署和优化一个基本的 Web 应用，使其成为完整的 PWA。最后，您将探索如何配置该应用使其可在 Android 和 iPhone 上安装和运行。完成本课程后，您将拥有在您希望的任何地方创建和部署自己的渐进式 Web 应用所需的 Ionic 和 PWA 技能和知识。

### [Ionic CLI](https://pluralsight.pxf.io/ionic-cli)

<!-- cspell:disable-next-line -->

作者：Pluralsight 的 Michael Callaghan

自成立以来，Ionic Framework 一直包含一个基本的命令行界面。虽然只有几年的历史，但它已经发展成为一个强大的工具，应该成为每个开发者工具箱的一部分。本课程"Ionic CLI"将从顶层开始探索 Ionic CLI。首先，您将看到如何创建项目和组件。接下来，您将学习如何构建和服务应用。最后，您将发现如何与他人共享项目，甚至与其他构建工具集成。无论您是刚接触 Ionic，还是从预测试版时代就开始使用它，这里都有适合您的内容。课程结束时，您将能够自信地在日常 Ionic 开发中使用 Ionic CLI。
