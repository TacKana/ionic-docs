在 Ionic 应用中存储数据有多种选项可供选择。

以下是两个官方的 Ionic 选项：

## Ionic Secure Storage

对于构建关键任务应用或需要加密支持团队，[Ionic Secure Storage](https://ionic.io/docs/secure-storage) 是 Ionic 团队的官方高级解决方案，提供适用于 iOS 和 Android 的跨平台数据存储系统。

它可以轻松构建跨 iOS、Android 和 Web 的高性能、可离线使用的 Ionic 应用。

[了解更多](https://ionic.io/products/secure-storage)

## @ionic/storage

对于不需要加密或关系数据支持的开发者，[@ionic/storage](https://github.com/ionic-team/ionic-storage) 是一个开源键/值 API，用于构建跨多个平台的存储引擎的应用。

此外，Ionic Secure Storage 提供了一个与 `@ionic/storage` 中的键/值 API 配合使用的驱动程序，同时提供加密和 SQLite 支持。

了解更多关于 [@ionic/storage](https://github.com/ionic-team/ionic-storage) 的信息
