Ionic Visual Studio Code 扩展可帮助您执行 Ionic 应用开发中常见的各种功能，而无需离开 VS Code 窗口。您可以在 [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=ionic.ionic) 上安装该扩展。安装完成后，您将在活动栏中看到 Ionic 图标。

## 创建新项目

在一个空目录中，您可以通过点击模板选项并提供应用名称来创建 Angular、React 或 Vue 项目。

<img
  src="https://user-images.githubusercontent.com/84595830/159510276-6766a5b8-132d-4284-a3fa-cd6374d64891.gif"
  alt="创建项目的视频"
/>

创建新项目后，该扩展将提供对 `package.json` 中所有常见任务的访问。

## 添加 Capacitor

您还可以通过选择"集成 Capacitor"来将 [Capacitor](https://capacitorjs.com/) 添加到您的应用中。

<img
  src="https://user-images.githubusercontent.com/84595830/159510570-b5a151bb-2e17-42c8-8cab-bffbaa849576.gif"
  alt="添加 Capacitor 的视频"
/>

集成 Capacitor 后，您现在可以通过"在 Web 上运行"、"在 Android 上运行"和"在 iOS 上运行"选项，在 Web、Android 和 iOS 上运行您的应用。

## 更多功能

Ionic VS Code 扩展功能丰富，可帮助您完成迁移、调试、monorepo 支持等更多任务。有关扩展所有功能的完整列表，请查看 [VS Code Marketplace 上的扩展概述](https://marketplace.visualstudio.com/items?itemName=ionic.ionic)。
