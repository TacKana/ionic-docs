标签（Tab）组件是[tabs（标签页）](tabs.md)的子组件。每个标签可以包含应用的顶层导航堆栈或单个视图。一个应用可以有多个标签，每个标签都有自己的独立导航。

:::note
注意：此组件仅应与 vanilla JavaScript 项目一起使用。对于 Angular、React 和 Vue 应用，你不需要使用 `ion-tab` 来声明标签组件。
:::

请参阅[tabs 文档](tabs.md)了解更多关于配置标签的详细信息。
