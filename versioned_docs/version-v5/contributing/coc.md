# 行为准则

作为 Ionic 项目的贡献者和维护者，我们承诺尊重每一位通过发布 issue、更新文档、提交拉取请求、在评论中提供反馈以及任何其他活动来做出贡献的人。

通过 Ionic 的任何渠道（GitHub、Slack、论坛、IRC、邮件列表、Twitter 等）进行的沟通必须具有建设性，绝不能诉诸人身攻击、钓鱼、公开或私下的骚扰、侮辱或其他不专业的行为。

我们承诺对参与此项目的每个人表示礼貌和尊重，无论其性别、性别认同、性取向、残疾、年龄、种族、民族、宗教或经验水平如何。我们期望任何为 Ionic 项目做出贡献的人也能做到这一点。

如果任何社区成员违反了此行为准则，Ionic 项目的维护者可以采取行动，酌情删除 issue、评论和 PR，或封禁账户。

如果你遭受或目击了不可接受的行为，或有任何其他问题，请发送电子邮件至 <a href="mailto:devrel@ionic.io">devrel@ionic.io</a>。

请点击<a href="https://ionic.io/code-of-conduct" target="_blank" rel="noopener">此处</a>查看 Ionic 的完整行为准则。
