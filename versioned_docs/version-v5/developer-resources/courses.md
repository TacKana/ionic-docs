### [使用 Ionic 和 Electron 构建桌面应用](https://pluralsight.pxf.io/VeMXO)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

桌面开发历来需要与 Web 开发截然不同的技能。这两个学科很难很好地融合。在本课程《使用 Ionic 和 Electron 构建桌面应用》中，您将掌握如何运用您辛苦学到的 Web 开发技能来构建出色的桌面应用程序。首先，您将学习如何使用 Ionic 和 Angular 构建功能完善且美观的 UI。接着，您将发现如何将该 UI 封装到 Electron 应用程序外壳中。最后，您将探索如何打包应用并使其准备好分发。完成本课程后，您将拥有在 Windows 和 macOS 上部署和分发精美应用所需的 Ionic 和 Electron 开发技能和知识。

### [使用 Ionic 构建渐进式 Web 应用](https://pluralsight.pxf.io/Ly2EY)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

当 Google 提出渐进式 Web 应用（PWA）的概念时，一切都发生了变化。PWA 是一种纯 Web 应用程序，可以安装在设备上，并通过智能缓存的使用，在网络功能有限的情况下正常运行。构建一个可以在任何地方运行的渐进式 Web 应用。在本课程《使用 Ionic 构建渐进式 Web 应用》中，您将学习基础知识，并获得创建可在任何地方运行的 Web 应用程序的能力：浏览器、桌面或移动客户端。首先，您将了解什么是渐进式 Web 应用（PWA）。接着，您将发现如何使用 Ionic 框架、Angular 和 Firebase 来创建、部署和优化一个基本的 Web 应用程序，使其成为完整的 PWA。最后，您将探索如何配置应用程序，使其可在 Android 和 iPhone 上安装和运行。完成本课程后，您将拥有在您想要任何地方创建和部署自己的渐进式 Web 应用所需的 Ionic 和 PWA 技能和知识。

### [Ionic CLI](https://pluralsight.pxf.io/ionic-cli)

<!-- cspell:disable-next-line -->

作者：Michael Callaghan（Pluralsight）

自诞生以来，Ionic 框架一直包含一个基本的命令行界面。虽然只有几年的历史，但它已经成熟为一个强大的工具，应该成为每个开发者工具箱的一部分。本课程《Ionic CLI》将从头开始探索 Ionic CLI。首先，您将了解如何创建项目和组件。接着，您将学习如何构建和提供服务。最后，您将发现如何与他人共享项目，甚至与其他构建工具集成。无论您是刚开始探索 Ionic，还是从预测试版时代就开始使用，这里都有适合您的内容。课程结束时，您将自信地将 Ionic CLI 作为日常 Ionic 开发的一部分。
