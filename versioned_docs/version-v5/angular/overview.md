# Ionic Angular 概览

`@ionic/angular` 将核心的 Ionic 体验与专为 Angular 开发者打磨的工具和 API 相结合。

## Angular 版本支持

Ionic 支持 `Angular 6.0.0 及以上版本`。作为其升级策略的一部分，Angular 提供了内置工具来帮助自动化升级过程，并在 API 发生变更时向开发者提供反馈。这减少了更新时的摩擦，使生态系统保持常青状态。

## Angular 工具链

从 Ionic 4 开始，我们使用官方的 Angular 技术栈来构建应用和路由，因此您的应用可以与整个 Angular 生态系统的其他优秀部分保持一致。在需要更多定制化功能的情况下，Ionic 提供了 `@ionic/angular-toolkit`，它构建并集成于[官方 Angular CLI](https://angular.io/cli) 之上，提供了针对 `@ionic/angular` 应用的特定功能。
