# 版本管理

<!-- TOC 在此处 -->

Ionic Framework 遵循 <a href="https://semver.org/" target="_blank">语义化版本控制（SemVer）</a>规范：<code>major.minor.patch.</code>。不兼容的 API 变更会增加 <code>major</code>（主版本号），添加向后兼容的功能会增加 <code>minor</code>（次版本号），向后兼容的 bug 修复会增加 <code>patch</code>（补丁版本号）。

## 发布计划

### 主版本发布

当 API 中引入了破坏性变更时，将发布主版本。主版本大约每 **6 个月**发布一次，可能包含破坏性变更。在主版本最终发布之前，将发布若干个候选版本，以便在最终版本之前收集反馈。候选版本将包含正在变更的内容和原因的概述。

### 次版本发布

当添加新功能或引入非破坏性的 API 变更时，将发布次版本。我们将对任何更改进行严格测试，以确保对发布充满信心，但新代码总是伴随着新问题的潜在风险。如果有任何功能或 API 变更，我们计划**每月**发布一个次版本。

### 补丁版本发布

当包含 bug 修复但 API 未更改且未引入破坏性变更时，将发布补丁版本。我们计划**每两周**发布一个新的补丁版本，但有时可能需要比计划更早或更晚发布。为确保补丁版本能够修复现有代码而不引入新功能带来的新问题，补丁版本总是在次版本之前发布。

## 变更日志

要查看 Ionic 所有重要变更的列表，请参阅 <a href="https://github.com/ionic-team/ionic/blob/master/CHANGELOG.md" target="_blank">changelog（变更日志）</a>。其中包含每个版本下所有 bug 修复和新功能的有序列表。
